# zmod_esp32-nfc has moved to LaneTag

This project is now **[LaneTag](https://github.com/DIEHARDave/LaneTag)**.

It is no longer specific to Flashforge printers or Zmod, so it has a new name
and a new repository. The full history moved with it; development continues
there.

**Already running zmod_esp32-nfc on a reader?** Build LaneTag and upload it
under **Settings > Firmware** on the reader's web page. Your Wi-Fi, printers
and other settings carry over.

The last zmod_esp32-nfc version is still available as commit
[8d2b526](https://github.com/DIEHARDave/zmod_esp32-nfc/tree/8d2b526) in this
repository's history.
